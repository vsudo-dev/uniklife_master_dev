# Branding

---

## What Is White-Label Branding?

Each tenant can customise the appearance of UNIKLIFE so it looks like their own product.  
Clients and staff of "Healthy Lifestyle" see their brand, not the UNIKLIFE brand.

---

## What Can Be Customised

| Setting | Description |
|---------|-------------|
| Business Name | Shown in the header and browser tab |
| Logo | Uploaded image shown in the top left |
| Primary Color | Main brand color (buttons, highlights) |
| Accent Color | Secondary brand color |
| Favicon | Small icon shown in the browser tab |

---

## How to Update Branding

1. Go to **Tenant Settings** (accessible from the left nav as Tenant Admin)
2. Click **Branding**
3. Update the fields:
   - Upload a logo (PNG or SVG recommended)
   - Enter hex color codes for primary and accent colors
4. Click **Save**

Changes apply immediately — refresh the page to see them.

---

## Color Format

Colors must be entered as hex codes:
- Example: `#1A73E8` for blue
- Example: `#FF6B35` for orange

---

## Logo Requirements

- File format: PNG, JPG, or SVG
- Recommended size: 200×60px or similar wide format
- Transparent background works best on light and dark headers

---

## Per-Tenant Isolation

Each tenant's branding is completely separate.  
Changing Tenant A's branding has zero effect on Tenant B.

---

## Who Can Update Branding?

| Role | Can Update |
|------|:----------:|
| Super Admin | ✅ (for any tenant) |
| Tenant Admin | ✅ (own tenant only) |
| Practitioner / Staff | ❌ |
