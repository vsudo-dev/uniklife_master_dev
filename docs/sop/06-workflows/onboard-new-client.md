# Workflow: Onboard a New Client

---

## Overview

This is the complete end-to-end process for onboarding a new wellness client into UNIKLIFE.

```
Sales team adds contact in MyAppz
        ↓
Contact syncs to UNIKLIFE (if tagged)
        ↓
Practitioner opens client profile
        ↓
Activates wellness profile
        ↓
Adds health assessment
        ↓
Creates care plan
        ↓
Enrolls in program (optional)
        ↓
Client is active and tracked
```

---

## Step-by-Step

### Step 1 — Sales Team: Add Contact in MyAppz
1. Open MyAppz CRM
2. Create a new contact (name, phone, email)
3. **Add the tag** `test_healthy-fitness` (or the tenant's configured tag)
4. Save

> Without the tag, the contact will NOT appear in UNIKLIFE.

### Step 2 — Wait for Sync
- UNIKLIFE receives a webhook from MyAppz automatically
- The contact appears on the **Clients page** within seconds
- No manual refresh needed

### Step 3 — Practitioner: Open Client Profile
1. Go to **Clients** in the left navigation
2. Find the new contact
3. Click **View**

### Step 4 — Activate Wellness Profile
1. On the client profile, click **Activate Wellness Profile**
2. The 7-tab view unlocks (Assessments, Progress, Care Plans, etc.)

### Step 5 — Add Health Assessment
1. Go to the **Assessments** tab
2. Click **New Assessment**
3. Fill in height, weight, blood pressure, goals, medical history
4. Save

### Step 6 — Create Care Plan
1. Go to the **Care Plans** tab
2. Click **New Care Plan**
3. Set title, duration, goals, and activities
4. Set status to **Active**
5. Save

### Step 7 — Enroll in Program (Optional)
1. Go to the **Programs** tab
2. Click **Enroll in Program**
3. Select the program and start date
4. Save

### Step 8 — Book Appointment
1. Go to **MyAppz calendar**
2. Book the appointment for this client
3. It will appear in UNIKLIFE automatically

## Checklist

- [ ] Contact created in MyAppz with correct tag
- [ ] Contact visible on UNIKLIFE Clients page
- [ ] Wellness profile activated
- [ ] Health assessment completed
- [ ] Care plan created and set to Active
- [ ] First appointment booked in MyAppz
