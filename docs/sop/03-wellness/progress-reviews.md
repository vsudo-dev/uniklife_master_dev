# Progress Reviews

---

## What Are Progress Reviews?

Progress reviews are regular check-ins between a practitioner and client to track how the client is doing.  
Two components: **Check-ins** and **Goals**.

---

## Check-ins

A check-in is a brief progress snapshot taken during or after a session.

| Field | Description |
|-------|-------------|
| Date | When the check-in happened |
| Mood | 1 (very low) → 5 (excellent) |
| Notes | What was discussed, observations |
| Status | Pending / Complete |

### How to Add a Check-in
1. Open the client's profile
2. Go to the **Progress** tab
3. Click **New Check-in**
4. Set the date, mood score, and notes
5. Save

### Check-in Statuses
- **Pending** — scheduled but not yet done
- **Complete** — done

---

## Goals

Goals are specific outcomes the practitioner sets for a client.

| Field | Description |
|-------|-------------|
| Title | What the goal is (e.g. "Lose 5kg") |
| Target Date | When to achieve it by |
| Progress | 0–100% (updated manually) |
| Status | Not Started / In Progress / Achieved / Missed |

### How to Create a Goal
1. Open the client's profile
2. Go to the **Progress** tab
3. Click **New Goal**
4. Enter the title, target date
5. Save

### Updating Goal Progress
- Click on the goal to edit
- Update the progress percentage
- Change status as the client advances

### Goal Status Transitions
```
Not Started → In Progress → Achieved
                          → Missed
```
