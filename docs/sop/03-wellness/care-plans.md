# Care Plans

---

## What Is a Care Plan?

A care plan is a personalised treatment or wellness plan created by a practitioner for a specific client.  
It outlines what the client needs to do, what the practitioner will provide, and the expected timeline.

---

## What It Contains

| Field | Description |
|-------|-------------|
| Title | Name of the plan (e.g. "12-Week Weight Loss Plan") |
| Description | Overview of the plan |
| Start Date | When the plan begins |
| End Date | When the plan ends |
| Goals | Specific measurable outcomes |
| Activities | What the client needs to do (exercise, diet, check-ins) |
| Status | Draft / Active / Completed / Paused |
| Notes | Practitioner notes |

---

## How to Create a Care Plan

1. Open the client's profile
2. Go to the **Care Plans** tab
3. Click **New Care Plan**
4. Fill in title, dates, goals, and activities
5. Set status to **Active** when ready
6. Save

---

## Care Plan Statuses

| Status | Meaning |
|--------|---------|
| Draft | Being prepared — not yet shared with client |
| Active | In progress |
| Paused | Temporarily on hold |
| Completed | Finished |

---

## Multiple Care Plans

A client can have multiple care plans over time (e.g. different phases of treatment).  
Only one plan should be **Active** at a time.
