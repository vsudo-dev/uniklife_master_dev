# Wellness Programs

---

## What Is a Program?

A wellness program is a structured offering (e.g. "12-Week Weight Loss", "30-Day Detox").  
Clients enroll in programs. Practitioners track their progress and completion.

---

## Programs vs Care Plans

| | Program | Care Plan |
|---|---------|-----------|
| What it is | A defined offering with a fixed structure | A personalised plan for one client |
| Who it applies to | Many clients can enroll | Created for one specific client |
| Created by | Tenant Admin / Practitioner | Practitioner |

---

## Program Structure

| Field | Description |
|-------|-------------|
| Name | Program title (e.g. "12-Week Weight Loss") |
| Description | What the program includes |
| Duration | How many weeks/days |
| Category | Type (Weight Loss, Detox, Strength, etc.) |
| Status | Active / Inactive |

---

## Enrolling a Client

1. Open the client's profile
2. Go to the **Programs** tab
3. Click **Enroll in Program**
4. Select the program
5. Set the start date
6. Save

---

## Enrollment Status

| Status | Meaning |
|--------|---------|
| Active | Currently enrolled and ongoing |
| Completed | Finished the program |
| Dropped | Left before completion |
| Paused | Temporarily on hold |

---

## Tracking Progress

Each enrollment tracks:
- Start date and expected end date
- Current status
- Completion percentage
- Practitioner notes

---

## Reports

The Reports page shows program enrollment outcomes across all clients — completion rates, drop rates, active enrollments. See [Reports](../04-operations/reports.md).
