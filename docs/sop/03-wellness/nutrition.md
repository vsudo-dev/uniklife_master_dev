# Nutrition

---

## What Is the Nutrition Module?

The Nutrition module allows practitioners to track a client's food intake and create personalised meal plans.

---

## Two Parts

### 1. Nutrition Logs
Daily food intake records for a client.

| Field | Description |
|-------|-------------|
| Date | Day of the log |
| Meal Type | Breakfast / Lunch / Dinner / Snack |
| Food Items | What was eaten |
| Calories | Total calories for the entry |
| Protein / Carbs / Fat | Macronutrient breakdown |
| Notes | Practitioner or client notes |

### 2. Meal Plans
Structured plans created by a practitioner.

| Field | Description |
|-------|-------------|
| Title | Name of the plan (e.g. "1500 Cal Deficit Plan") |
| Start / End Date | Duration of the plan |
| Daily Calorie Target | Target calories per day |
| Meals | Breakfast, lunch, dinner, snacks with food suggestions |
| Notes | Special instructions |

---

## How to Add a Nutrition Log

1. Open the client's profile
2. Go to the **Nutrition** tab
3. Click **Add Log**
4. Select date and meal type
5. Enter food items and quantities
6. Save

---

## How to Create a Meal Plan

1. Go to the **Nutrition** tab
2. Click **New Meal Plan**
3. Set the title, dates, and calorie target
4. Add meals with food items
5. Save
