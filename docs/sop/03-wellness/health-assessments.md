# Health Assessments

---

## What Is a Health Assessment?

A health assessment is a structured record of a client's physical health at a point in time.  
Created by a practitioner during an initial or follow-up consultation.

---

## What It Captures

| Field | Description |
|-------|-------------|
| Date | When the assessment was done |
| Height | In cm |
| Weight | In kg |
| BMI | Calculated automatically |
| Blood Pressure | Systolic / Diastolic |
| Resting Heart Rate | BPM |
| Blood Sugar | Fasting / Post-meal |
| Health Goals | What the client wants to achieve |
| Medical History | Existing conditions, medications |
| Notes | Practitioner's notes |

---

## How to Add an Assessment

1. Open the client's profile
2. Go to the **Assessments** tab
3. Click **New Assessment**
4. Fill in the fields
5. Save

---

## Assessment History

All past assessments are stored and viewable.  
Useful for tracking changes over time — e.g. weight trend, BMI improvement.

---

## Who Can Add / View?

| Role | Can Add | Can View |
|------|:-------:|:--------:|
| Super Admin | ✅ | ✅ |
| Tenant Admin | ✅ | ✅ |
| Practitioner | ✅ | ✅ |
| Staff | ❌ | ❌ |
| Customer | ❌ | Own only (future) |

> Health data has stricter access than regular business data — staff cannot see it.
